# 封面设计规范

> 本文件是内容平台封面设计的唯一事实来源。所有封面产出须通过文末验收清单。

## 设计目标

为不同内容平台一键生成视觉统一、文案安全、比例合规的封面/头图/配图。核心矛盾是「平台尺寸约束」与「视觉冲击力」的平衡--各平台比例与安全区不同，但同一内容的各平台封面须保持视觉统一，形成可识别的封面矩阵。

封面是内容的「门面」，在信息流中被拇指快速划过，须在 0.5 秒内传达核心信息并吸引点击。

## 平台规格总表

| 平台 | 比例 | 推荐尺寸 | 安全区要点 |
|------|------|---------|-----------|
| 微信公众号 头图 | 2.35:1 | 900×383 | 核心元素居中，避开两侧裁切 |
| 微信公众号 方图 | 1:1 | 900×900 | 安全区内缩 10% |
| 小红书 封面 | 3:4（竖图） | 1080×1440 | 标题避开底部 20%（信息流预览裁切） |
| 小红书 方图 | 1:1 | 1080×1080 | 同上 |
| YouTube 缩略图 | 16:9 | 1280×720 | 安全区见下方示意，移动端裁切严重 |
| Bilibili 封面 | 16:9 | 1146×717 | 右下角避开时长水印，底部避开标题叠层 |
| 抖音/快手 封面 | 9:16（竖图） | 1080×1920 | 顶部状态栏 + 底部文案区，核心居中 |
| 视频号 封面 | 3:4 或 1:1 | 1080×1440 | 信息流裁切比例同小红书 |
| Twitter/X | 16:9 | 1600×900 | 核心元素居中 50% |
| Instagram 帖子 | 1:1 / 4:5 | 1080×1080 / 1080×1350 | 4:5 在信息流更抢眼 |

### YouTube 安全区示意

YouTube 在不同设备裁切差异极大，核心信息须收在安全区内：

```
┌───────────────────────────────┐
│      ┌─────────────────┐      │  <- 裁切区（移动端/嵌入可能裁掉）
│      │                 │      │
│      │   核心标题/图像   │      │  <- 安全区（1280×720 居中 60%）
│      │                 │      │
│      └─────────────────┘      │
│      ┌─────────────────┐      │  <- 时长水印（右下角，避开）
└───────────────────────────────┘
```

## 操作流程

### C1. 内容解构

从用户输入提取：

- **主标题**：封面核心信息，≤ 15 字为佳（信息流快速可读）
- **副标题**：可选，补充说明，≤ 10 字
- **可选图片**：用户上传原图或指定背景风格
- **目标平台**：可多选，多选时生成封面矩阵
- **风格标签**：科技 / 美食 / Vlog / 简约 / 情感 / 等

标题过长是封面可读性的最大杀手。主动建议用户精简，或拆为主副标题两层。

### C2. 平台匹配与安全区

按 C1 目标平台，从平台规格总表匹配比例与尺寸。关键约束：

- 核心标题/主体必须落在安全区内，防止信息流预览裁切丢信息
- YouTube 右下角避开时长水印
- 小红书/视频号底部 20% 在信息流中被裁，不放核心信息
- 抖音/快手顶部状态栏 + 底部文案区不放核心信息

### C3. 视觉方向

基于风格标签和品牌基线（若有，见 `specs/brand`），确定：

- **色彩基调**：与内容调性匹配（科技冷色 / 美食暖色 / 情感柔和色）
- **背景策略**：纯色 / 渐变 / 图片融合 / 图形底纹
- **字体配对**：有性格的展示字体 + 可读性强的副标题字体
- **构图方向**：居中对称 / 左文右图 / 上文下图 / 对角线 / 满版出血

一个封面矩阵（同内容多平台）须统一视觉方向，仅按平台比例调整构图。

### C4. 标题排版

封面可读性的核心。规则：

- 标题字号占封面高度 ≥ 15%（信息流缩略图下仍可读）
- 标题与背景对比度 ≥ 4.5:1（WCAG AA），暗背景用浅字、亮背景用深字或描边
- 标题不超出安全区
- 文字行数 ≤ 3 行，每行 ≤ 8 字为佳
- 长标题拆为主副：主标题大号粗体，副标题小号常规
- 标题可加描边/投影/半透明底板增强对比度，但不喧宾夺主

### C5. 多平台矩阵生成

同一内容一次性生成所有选定平台的封面矩阵，保持视觉统一：

- 主标题文字/主体图像在所有平台一致
- 按各平台比例调整构图（如 16:9 横排 -> 9:16 上下排）
- 色彩、字体、风格在所有平台保持一致
- 每张封面独立通过安全区检查

矩阵是封面设计的核心价值--一次内容、多端覆盖、视觉统一、频道辨识。

### C6. 导出

**可审阅封面矩阵 HTML**（首选）：单页 HTML，将多平台封面并排展示供一致性审阅

- 每平台一个区块：封面预览图 + 平台名 + 比例 + 尺寸 + 安全区标注
- 弹出式审阅（见 `specs/review`）：每平台区块有 [+] 按钮，点击弹窗写反馈 + 快捷标记
- 支持导出 Markdown/JSON 给 AI 修改，保留上一轮反馈对比
- 用于独立封面任务或项目流程中的封面审阅检查点

**正式导出文件**：

- 格式：JPG（照片类）/ PNG（图形类，需透明则 PNG）
- 分辨率：按平台规格总表，不低于推荐尺寸
- 色彩空间：sRGB（各平台默认）
- 文件命名：`<平台>_<主题>.jpg`（如 `youtube_ai-search.jpg`、`xiaohongshu_品牌色板.jpg`）
- 可选导出：分层源文件（PSD/Figma），供二次编辑

封面矩阵 HTML 定稿后导出正式文件。

## 验收标准

- [ ] 封面尺寸与目标平台比例精确匹配
- [ ] 核心标题落在安全区内，信息流预览不丢信息
- [ ] 标题字号占封面高度 ≥ 15%
- [ ] 标题与背景对比度 ≥ 4.5:1
- [ ] 标题行数 ≤ 3 行，每行 ≤ 8 字
- [ ] YouTube 右下角无核心信息（避开水印）
- [ ] 小红书/视频号底部 20% 无核心信息
- [ ] 多平台矩阵视觉统一（色彩/字体/风格一致）
- [ ] 色彩空间为 sRGB
- [ ] 文件命名含平台标识
- [ ] 暗背景浅字 / 亮背景深字，对比度达标

## 边界与不做项

- 不负责内容文案撰写（封面基于用户提供的标题/副标题）
- 不负责视频本身或文章正文
- 品牌视觉基线（色彩/字体）见 `specs/brand`，封面复用品牌色
- Web 页面内的 Hero 区设计见 `specs/web`，本规范仅覆盖独立封面/头图
- 移动端启动图/App 图标见 `specs/mobile`，与本规范无重叠
